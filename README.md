# Tableaux du cas Saveur

Fiche de révision interactive du cours de diagnostic financier : bilan, compte de résultat, SIG et CAF du cas Saveur, reliés ligne par ligne.

Survole une ligne pour lire son explication, clique dessus pour surligner ses liens dans tous les tableaux. Rose = la ligne choisie, jaune = même montant, bleu = lien de calcul.

Tout tient dans `index.html` (HTML, CSS et JavaScript, sans dépendance).
